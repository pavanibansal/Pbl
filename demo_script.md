# Demonstration Script
## Issue Triage and Developer Assignment Tool

### 1. Introduction

Good morning.

Our project is titled **Issue Triage and Developer Assignment Tool**.

It is developed in C and demonstrates how algorithms can be used to manage software development issues and assign tasks to developers based on their skills and available working hours.

### 2. Demonstration Scenario 1 – Issue Management

First, we will demonstrate issue management.

- Display the existing issue dataset.
- Add a new issue.
- Show the issue details.
- Update the issue status.

This demonstrates how the application maintains and manages software issues.

### 3. Demonstration Scenario 2 – Sorting and Searching

Next, we will demonstrate Merge Sort and Binary Search.

- Select the sorting option.
- Show issues arranged according to priority.
- Select the searching option.
- Enter an issue ID.
- Display the matching issue.

This demonstrates sorting and searching techniques.

### 4. Demonstration Scenario 3 – Developer Assignment

Next, we will demonstrate developer assignment.

- Display the available developers.
- Select the assignment option.
- The application checks skill requirements.
- It checks available working hours.
- It checks whether dependencies are completed.
- The 0/1 Knapsack algorithm selects suitable issues.

The application then displays the assigned issues and updates developer workloads.

### 5. Reports and Data Storage

Finally, we will display the project report.

It shows the total number of issues, their status, and developer workloads.

We will also demonstrate saving the updated information in CSV files.

### 6. Algorithms Explained

The project demonstrates:

1. Merge Sort for sorting issues.
2. Binary Search for searching issue IDs.
3. 0/1 Knapsack for selecting issues within developer capacity.
4. Dijkstra's Algorithm implemented for shortest-path calculation.

### 7. Conclusion

Through this project, we demonstrate how algorithmic techniques can solve practical problems related to issue management and developer assignment.

Thank you.
